GoodObsidian — toolbar

Two tiers: a tinted full-width tool bar, and a floating pill holding the active tool's options.

The two tiers, together

3 / 18

Tier 1 is a full-width bar tinted with --interactive-accent: document actions left (thumbnails · search · transcribe · outline), page and history controls centre, tools right (lasso · pen · eraser · text · shapes · image · sticky note · laser · microphone). The active tool is a light filled rounded square against the tint. Tier 2 is a floating pill holding only the active tool's options. Switch the theme above: every colour here is an Obsidian variable, so the bar follows the user's accent rather than imposing a GoodNotes blue.

Disabled buttons are deliberate. Text, image, sticky note, laser, microphone, thumbnails and search are in the design but have no model behind them yet, and a control that silently does nothing is a worse failure than one that says it is not ready.

Pen, eraser, lasso. The pen pill is the reference screenshot's layout: four pen types (active tinted and lifted, with a chevron), a divider, three stroke widths drawn as literal strokes of increasing weight with the active one boxed, a chevron for more, then colour swatches and a dashed circle with a +.

Touch targets

Every control is at least 44 × 44 CSS px (--gob-touch), including the colour swatches — the button is full size and background-clip: content-box paints only the inner disc, so the target is generous without the pill looking like a row of blobs.
