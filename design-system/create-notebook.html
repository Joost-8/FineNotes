Modelled on the second reference screenshot. The left rail is a live preview (title, cover, paper) and the right pane is the picker: filters along the top with a portrait/landscape segmented toggle at the far right, then a scrolling grid grouped under Essentials, Writing papers and Planner. Orientation costs nothing in the model — landscape is the same page geometry with width and height swapped — and Planner templates are why the ruling table in src/canvas/backdrop.ts is a table.

Status: design only. This dialog is not implemented in the plugin yet; the preview exists so the shape is agreed before anyone builds it.
