# Code of conduct

FineNotes' issues, Discussions and pull requests are for helping each other make a better notebook.

- Be respectful. Disagree with ideas, not with people.
- No spam or self-promotion.
- Keep it about FineNotes.

The maintainer may edit or remove posts, and block people, who break these rules.

To report a problem privately, email finenotes0@gmail.com.
